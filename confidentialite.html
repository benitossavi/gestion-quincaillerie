Règles de confidentialité

Dernière mise à jour : 21 novembre 2026

1. Qui sommes-nous

GestionQuincaillerie est un logiciel de gestion commerciale développé par Benoît TOSSAVI (Bénin) et installé sur l'ordinateur ou le serveur de chaque commerce client. Contact : benitossavi@gmail.com.

2. Où sont les données du commerce

Les données gérées par GestionQuincaillerie (clients, fournisseurs, produits, ventes, achats, caisse, personnel, salaires...) sont enregistrées dans la base de données installée sur l'ordinateur ou le serveur du commerce. Le commerce en est responsable. Le développeur ne reçoit pas ces données et n'y a pas accès.

Une sauvegarde de la base est faite chaque jour sur ce même ordinateur. Le commerce peut en garder une copie ailleurs (clé USB, disque externe).

3. Ce qui sort de l'installation

Seules les informations suivantes quittent l'ordinateur du commerce, pour le fonctionnement du logiciel :

  • Abonnement : lors d'un achat d'abonnement en ligne, l'identifiant de l'installation, le nom du commerce et la formule choisie sont envoyés au serveur de licences du développeur, pour délivrer le code d'activation. Aucune donnée de gestion n'est envoyée.
  • Paiement : le paiement est traité par le prestataire de paiement en ligne (FedaPay), selon ses propres règles de confidentialité. Le développeur ne reçoit ni le numéro de carte ni le code Mobile Money.
  • Facture normalisée : si le commerce l'active, les factures sont transmises au service e-MECeF de la Direction Générale des Impôts du Bénin, comme l'exige la réglementation fiscale, avec les identifiants fiscaux du commerce.
  • Mises à jour : l'application vérifie régulièrement si une nouvelle version est disponible sur GitHub. Cette vérification ne transmet aucune donnée du commerce.
  • E-mails : si le commerce configure son propre compte de messagerie, les e-mails envoyés par l'application (notifications, documents) partent par ce compte.

4. Accès par Internet (facultatif)

Si le commerce souhaite utiliser le logiciel hors de ses locaux, l'accès passe par une connexion chiffrée (HTTPS) mise en place sur l'ordinateur du commerce. Chaque utilisateur se connecte avec son propre compte et son mot de passe.

5. Vos droits

Pour consulter, corriger ou supprimer des informations vous concernant dans GestionQuincaillerie (en tant que client, fournisseur ou employé d'un commerce), adressez-vous au commerce concerné, qui gère ces données. Pour toute question sur ces règles : benitossavi@gmail.com.
